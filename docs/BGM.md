# BGM

- `assets/audio/theme.mp3`：原评委审核版，正常局势及主菜单播放。
- `assets/audio/poyanghudanger.mp3`：危机曲，仅由局势自动触发。两首均循环，设置中的曲目显示随当前播放更新。
- 已预警、下一次结算会爆发的危机触发危机曲；爆发后，受损指标补回实际损失的 50%（向上取整）即可解除，例如 80 → 66，恢复到 73 即达标。多个危机的修复目标合并，状态保存到存档。旧存档的剩余修复量减半。两回合后的深预告本身不会触发。即使修复达标，预测仍有判负风险时继续播放危机曲。
- 无危机时，如果指标悬停预测的 `break_total` 为真，也触发危机曲：自然变化、人鸟矛盾、下一次结算的危机影响按现有 HUD 预测计算，水位没有直接判负线。
- 进入危机直接切换；解除后主题曲从头以 75% 速度播放，3 秒内按正弦曲线恢复至正常速度。Godot 的 `pitch_scale` 同时影响速度和音高。过渡期间再次进入危机，取消过渡并立即正常播放危机曲。
- 结算动画及结算弹窗保留原有危险状态，下一回合进入后重新预测，避免用已结算的数值重复预测本回合。失败报告使用危机曲，通关及主菜单使用主题曲。

验证：`godot --headless --path . --script res://tools/verify_bgm.gd`。测试用精简主场景夹具，避免启动正式 UI 和读写玩家存档。
