# 生态监测 UI 动效（0.1.11）

六项监测图标共用 `metric_icon_effect.gd` 与顶点着色器。悬停约放大至 1.35 倍，鼠标离开平滑回正；左键点击产生 0.28 秒衰减轻震与回弹，连续点击重启反馈。着色器只改变显示顶点，不修改容器布局与原有算分动画使用的位置、缩放或旋转。

计量条在原填充上方、参考区间与红线上方之前加入独立波纹层。周期波峰沿屏幕从左到右移动，以当前 ProgressBar 显示值裁切并匹配圆角，不向空白部分渗出。动画时钟用帧时间推进，不使用 shader TIME，以便暂停冻结。波纹透明度为 0.22，保持原指标配色与参考线可读性；不响应鼠标、不阻挡悬停小窗。

暂停冻结交互动画。减少动态效果时图标即时响应悬停，取消点击震动，隐藏流动波纹。隐藏沙盘界面后波纹停止推进。两类效果不读取或修改游戏随机数，也不修改生态数值。

隔离存档图形回归 `METRIC_EFFECTS: 67 checks, 0 failures`，覆盖六项悬停放大与恢复、点击与连续点击、布局和算分变换独立性、实际数值裁切、暂停、减少动态效果、生态状态不变与随机数保护。画面见 `docs/screenshots/metric-effects/monitor-effects.png`。
