# motion-web 在保卫鄱阳湖中的适配

来源：[feitangyuan/motion-web](https://github.com/feitangyuan/motion-web)，2026-10-08 获取。作者 feitangyuan，CC BY-NC 4.0；许可证原文保存在 `licenses/motion-web.txt`，随游戏资源包导出。制作人员页面也包含来源、许可链接和 Godot 适配说明。该许可允许非商业学习与改编；商业使用需另获作者授权。此次没有推送或发布游戏。

用户要求把能用于当前游戏的动效加入游戏。沿用已确认的技术选择：保留 Godot/GDScript，网页机制改为原生输入、绘制与物理响应；GSAP 继续仅用于独立开发预览。这里交付的是实时游戏适配，不是把七个网页或其视觉皮肤嵌入游戏。

## 七类案例如何映射

| 仓库案例 / 方法 | 当前游戏中的位置 | 玩家看到的行为 |
|---|---|---|
| `string-clock`：柔性笔画、准确端点 | 左侧季节盘、左下出牌档位拉杆 | 指针弹簧转动，笔画随速度略弯，尖端落在真实季节刻度；木杆绕固定轴弹性摆向三个档位 |
| `press-stack`：层次与分段响应；motion-tokens 按压弹簧 | 主菜单、执行行动、调度、设置、天赋树等统一样式按钮；右侧行动图鉴牌堆 | 按下时轻微压缩，释放后回弹并恢复精确原尺寸；接触圈限于按钮内部；三张牌背逐层展开和收回 |
| `wheel-rail`：输入驱动、惯性、不同深度增益 | 更新日志、成就、危机回顾、牌库、知识图鉴、调度列表、天赋树；主菜单标题组 | 滚轮累计目标后平滑靠近，停下后准确落定；标题、眉题、副标题以 2/7/4 px 的不同增益响应指针 |
| `toy-flipbook`：硬切帧、11 Hz 保持、有限接触反应 | 被拒绝的手牌；回应湖面手势的水鸟 | 卡牌拒绝反馈使用低频保持的像素抖动，再归位；鸟类回应使用现有图集的单帧硬切，不混合两张姿势 |
| `char-curtain`：独立 Verlet 绳、局部推力 | 主菜单标题下的十四株芦苇 | 移动鼠标拨过时，附近芦苇独立弯曲；远处保持原位，停止后回到静止并休眠 |
| `ink-crowd`：正确的场景指向、位置响应 | 湖面与已有像素水鸟 | 从屏幕位置反算真实水面坐标，附近水鸟靠近输入位置；没有用“反应计数”代替实际位移 |
| `lyre-crows`：输入→有上限的发射→转向→既有对象回应 | 湖面点按或快速扫过，附近水鸟 | 输入产生短暂涟漪，附近水鸟以有限转向力靠近，捕获后啄食并发出短暂回应弧线；未捕获的涟漪也会过期 |

牌库、知识卡和调度卡的悬停浮起/归位也改为弹簧：快速移入移出时保留当前姿势和速度；排序接管卡牌时停掉悬停弹簧。此前 onetake 的详情承接、单一卡面和返回来源逻辑保留。

## 适配边界

使用现有像素卡面、鸟类图集和湿地色板。不照搬网页品牌、字体、商品图、墨鸦文字尾迹、全屏滚动叙事和黑白 WebGL 描边；这些与当前像素地图和卡牌阅读用途不符。长列表保留原生 ScrollContainer，鼠标拖动滚动条、焦点导航和触摸继续由 Godot 处理；最内层列表优先响应滚轮，到边界时不强行吞掉输入。

主菜单仍然是可直接操作的界面，新增视差最大只有数个像素；说明文字没有被拆成难以阅读的动态字符帘。物理芦苇占用已有标题与按钮间的空间，碰撞范围不影响按钮命中。鸟类只用自己的景观状态响应，不改变玩法指标、资金、种群、卡牌或随机结果。

## 原生实现与运行约束

- `scripts/motion_web.gd`：解析弹簧、与帧率无关的跟随、限转向力、保持式抖动、独立 Verlet 绳。弹簧按真实经过时间计算，绳索按 120 Hz 固定步长求解，不使用每帧固定乘数决定速度。
- `scripts/motion_spring.gd`：节点绑定的属性弹簧。重新指定目标保留当前值与速度；到达后写入精确终点并停止处理；节点销毁自动释放。
- `scripts/motion_button.gd`：统一样式按钮的按压、释放、鼠标/键盘响应和局部接触圈。重复设置按钮主题不会重复挂载。
- `scripts/motion_scroll.gd`：原生滚轮惯性。滚动条或键盘焦点引起的原生变化取消旧惯性，避免与用户拖动抢位置。
- `scripts/motion_parallax.gd`、`motion_reeds.gd`、`motion_impact.gd`：局部视差、独立芦苇和有限拒绝抖动。没有持续的随机漂浮或无限粒子。
- `scripts/wooden_tier_lever.gd`：游戏 HUD 中的原生 3D 木杆与半圆木座，鼠标拖动时跟手，释放后弹簧吸附到左、中、右三个档位；嵌入式视口仅在可见时渲染。
- `scripts/pixel_wetland.gd`：水面投射、转向和回应。最多四个兴趣点、0.8 秒发射间隔、4 秒无条件过期；水鸟不能因回应走到陆地，原有飞行与栖息状态不被吸引。

新增物理动效遵守游戏现有暂停状态，暂停面板上的按钮本身仍可操作。减弱动效时，弹簧直接落定、视差还原、不发射湖面反应、芦苇回到原位；内容和操作仍可见。隐藏界面不会持续刷新装饰，弹簧、视差、芦苇及滚轮达到静止后停止逐帧处理。

## 验证入口

`tests/motion_web.tscn` 使用真实 Godot 输入分发测试鼠标按下/释放、键盘激活、滚轮、鼠标拨动芦苇、菜单深度响应和湖面点击；同时检查弹簧的 30/60/120 Hz 一致性、速度连续性、静止休眠、暂停、减弱动效、链接伸长上限、准确季节刻度、兴趣点上限与过期，以及资金/指标/玩法随机序列不受景观输入影响。

2026-10-08 验证：19 个引擎测试场景经修复、定向复测全部通过。其中新动效交互 48 项、卡牌陀螺仪与真实指针 473 项、界面检查 941 项；其余覆盖卡牌图集、详情、排序、结算、天赋树、地图、四季与性能。修复了移动卡牌导致滚轮目标失效、列表末端重复滚轮跳变，以及弹窗下背景列表接收原生滚轮的问题。输入测试在按钮点击前重新定位指针，芦苇休眠测试先移出交互区域，避免继续输入影响静止断言。

最终资源包独立加载检查 15/15 通过：原生脚本和许可文件可用，30/120 Hz 弹簧计算一致，开发预览的 GSAP/onetake JavaScript 未进入游戏包。改动保存在本地，尚未提交或推送。
