# 狄鑫斛彩蛋知识卡

第二个制作组彩蛋，名字取自碟形湖。画作来自开发者 Oliveira 为组内成员绘制的讲解图，使用其小人原图，明确标注为创作人物而非真实物种。

每个符合知识卡间隔要求的回合独立掷一次 3% 概率。彩蛋成功时占用该回合唯一知识卡名额；未成功时继续原来的普通知识卡规则。同局不重复，掉落后下一回合不掉知识卡。季节、行动、指标、标签和收藏补齐均不会提高彩蛋概率。不是每个自然回合都有 3% 概率，因为间隔闸门仍然适用。

获取弹窗加入旋转展开动画。整张卡面使用统一的半透明闪箔膜，覆盖背景、原图、标题和名称；包含环形衍射纹、三角折射色块、细密反光颗粒及缓慢移动的斜向镭射光带。控制覆膜透明度，保留黑色线条和文字的可读性。只用单层卡面着色，不读取屏幕纹理。图鉴和详情共用卡面效果，未收集时仍然隐藏。下一弹窗清理专属展示节点。

测试：knowledge_cards 场景包含 2000 次固定种子抽取、强行注入条件仍不能触发彩蛋、间隔、存档、卡面布局和弹窗清理检查。所有存档测试在独立用户目录运行。

牌库白卡修复：倾斜绑定不再覆盖标记为独立覆膜的材质，覆膜着色器使用相同的顶点透视公式，并同步倾斜角和卡面中心。覆膜的透明度跟随父卡淡入淡出。知识卡 244 项、原有卡牌倾斜 373 项检查通过；从导出 EXE 的内嵌资源包验证牌库和详情的实际像素，两处都含有清晰黑色线条和亮色纸面。
