# 手牌边缘悬停稳定性（0.1.13）

原悬停判定仅检查动画中的卡面。鼠标停在边缘时，抬起导致卡面离开鼠标，从而退出悬停；落回又命中，产生重复上下弹跳。

现在进入悬停使用稳定的素材 alpha 轮廓：依据扇形基础位置、原角度、选牌抬起状态和当前手牌父层变换计算，不受悬停缩放、倾斜或抬起动画影响。已悬停的卡牌同时保留当前真实卡面作为退出判定的一部分；鼠标离开初始轮廓和当前卡面后正常退出。

稳定变换通过只读几何参数计算，不临时移动节点。点击仍使用当前可见透视卡面和透明像素判定，保持 0.1.9 的精确点击范围。排序、飞牌、算分与沙盘收起的原有交互边界保持不变。

图形隔离测试：`CARD_GYRO: 435 checks, 0 failures`。新增鼠标静止在上下左右四侧各 120 帧的检查：每次只有一次悬停激活，最终位移收敛而不反复跳动；离开后释放悬停并回到基础位置。同时保留素材透明边缘、陀螺仪、独立阴影、戳动、详情点击与真实 GUI 输入回归。
