# 右上角小牌桌（2026-10-10）

右上生态监测栏左边增加像素木板，最多容纳 5 张牌（简单模式 4 次普通行动＋1 张紧急调度）。使用 Soulofkiran 的 CC0 木质 UI 素材，来源及许可见 `licenses/wooden-gui.txt`。原始精灵表保存在 `assets/ui/wooden_gui_32x32.png`，AtlasTexture 取木板区域，九宫格拉伸；不在运行时下载。

- 手牌向上轻滑 24 个逻辑像素即可进入待出状态，松开左键才确认。松手前滑回原位可以取消；普通点击继续不出牌。
- 手牌也可直接拖到木板，松手后立即进入待执行队列，跳过展示倒计时和弧线飞行；预算、行动位和五张上限仍照常校验。
- 木板队列变化时，以独立状态副本预演本回合结算，六值条只在当前值与预计值间闪烁同色变化段；减少时闪烁移除段。未上木板的牌不计入预览。预览包括到期效果、协同、自然演化和已预警危机，季节水位按本局种子与回合固定一次随机结果，预览和实际结算共用；六值联动按完整结算顺序计算。预览不扣钱、不改真实状态，不消耗游戏随机序列；无变化不闪烁，减少动态模式静态显示。
- 出牌先在原已打出区以完整尺寸展示 1 秒，再用 0.58 秒弧线飞往木板并缩小为 50%。木板上横排，中心间距 63 像素，牌边间距 2 像素。
- 原已打出区和木板上的牌都可以拖动。横向移动按固定槽位让邻牌避让，松手后确定顺序；向下滑 34 像素且以向下为主，离开木板后松手即可悔牌，0.44 秒放大回到手牌。
- 紧急调度悔牌会退回牌库并退还实际支付的调度费，同步撤销消费账本、调度次数和冷却；普通牌仍返回手牌。
- 还有牌留在已打出区或飞往木板时，执行行动按钮不可用。全部落到木板后，已选牌沿弧线放大回原结算行，再按队列顺序回放效果和分数。游戏数值计算仍只执行一次。
- 木板为 340×124，删除箭头。查看沙盘时木板上的牌临时随木板一同向右移出，展开完成后恢复卡牌父节点，期间保持牌和木板相对静止。

`card_flight.gd` 对同一张卡的中心位置、缩放和旋转统一驱动；中途不换图片或重新创建牌面。尾迹只用 8 个采样点和 7 条渐细线段，没有粒子、重复卡面贴图和整屏模糊，落地即删除节点。独立线段也避免原地短距离飞行时的多边形自交。拖动时同一帧更新尺寸、角度和抓握点位置，缩放不改变鼠标抓住的位置。静止木板没有 process 回调；布局只在卡数、拖动、尺寸变化和区域切换时更新，复用现有静止后休眠的弹簧。

暂停冻结飞行；减少动态设置直接展示终点；牌库、调度面板和查看沙盘期间暂停展示倒计时。木板跟随 HUD 收起。窗口最小尺寸 960×540 下仍容纳完整五牌，不覆盖监测栏。

验证使用独立 Godot 项目副本和独立存档目录：

```powershell
python tests/prepare_visual_test.py staged_board build/staged-board/validation
# 用 Godot --editor --import --quit 导入，然后运行该项目。
# POYANG_SCREENSHOT_DIR 指向截图目录时，图形测试会导出关键帧。
```

`tests/staged_board.gd` 覆盖轻滑、松手确认、手势反悔、展示倒计时、连续缩放飞行、暂停、两个区域悔牌、真实 GUI 命中与鼠标释放、五牌等距布局、换位、调度牌退回牌库、退费与读档、减少动态、最小窗口、放大回结算、顺序和动画节点回收。既有快速结算、调度顺序、预算、悬停提示等测试继续用于回归。

- 真实图形窗口发牌：83 项；悬停提示：62 项；查看沙盘：69 项；动画生命周期：18 项。
- 运行开销回归：796 项，不变轮廓 30 帧重绘 0 次，静止弹簧 10000 次重复请求唤醒 0 次。
- 关键帧：`docs/screenshots/staged-board/`。测试使用独立玩家目录，不改真实存档。

原发牌测试改为等待实际排序流程结束，避免在 120 FPS 下用固定 75 帧提前重建手牌。悬停测试从卡牌当前实际位置指定换位目标；沙盘测试使用拖牌和停靠，替代已经移除的旧点击选牌函数。断言继续检查实际画面和状态，不跳过失败场景。
