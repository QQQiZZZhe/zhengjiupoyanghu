# 四季换景动画

实际季节变化时，约1.15秒的柔和色带从屏幕顶部扫到底部，替换外围地面、树冠及装饰色彩。着色器与景物使用相同的屏幕位置和进度，覆盖中央地图、外围地面、菜单拉远、窗口变化及彩蛋空地。水域不参与季节染色。

春季花丛稀疏绽放，夏季花丛铺开，进入秋冬时花朵缩小收拢，并飘落少量花瓣。春夏花瓣轻飘、秋季落叶、冬季全屏飘雪，风带来轻微横向摇摆。天气位于景物上方、界面下方，每帧最多180片粒子；避开彩蛋投影范围及12像素留白。花丛继续避让彩蛋、建筑和水域。

季节变化使用独立进度；同一季节的指标同步不会重启换景。返回菜单和调整窗口会保留进度；暂停时停止，恢复后继续。减少动态效果时立即完成变色、停用天气和花丛摇摆，保留四季静态景色与花丛。装饰与天气使用固定数学分布，不消费游戏随机数，不改变生态或存档数值。

tests/seasonal_animation.gd逐帧检查完整冬→春→夏→秋→冬循环，覆盖新旧画面端点、扫描方向、重复同步、花开花落、对应天气、粒子上限、彩蛋避让、窗口变化、减少动态效果以及随机数和玩法状态不变。4046项检查通过。四季全视野回归seasonal_scenery的12078项检查通过。

地图回归map_render通过981项检查；17625个水面采样点未受到接触阴影影响。比较接触阴影开关时隐藏独立天气层，避免把移动花瓣误认为阴影变化。

实际渲染的52帧保存在docs/screenshots/seasonal-animation/cycle-00.png至cycle-51.png；season-cycle.gif为循环预览。动画本体位于scripts/pixel_wetland.gd及scripts/wetland_ground.gdshader。
