# 长江渔船

长江与湖区统一使用 `wetland-sprites.png` 中的渔船贴图和 60×62 绘制尺寸。长江船只按平滑后的河道方向转向，并补偿原贴图斜向船头的角度。旋转中心放在船身上，船头与航行方向一致；湖区渔船保留原有摆放。

航行速度从每秒 0.007 个全航程降至 0.00035，约为原速度的 1/20。相反方向的船使用中心线两侧各 0.010 UV 的航道；用前后路径采样平均方向，减轻折点处航道横向跳动。航程循环在远离画面的河道延长段发生。长江半宽从 0.017 增至 0.030，水面、岸边和水域判定共用新宽度。

验证：`map_render` 1778 项通过，其中 800 项检查船只航道余量、连续位移、行驶方向及船头朝向；18193 个水面采样点无错误阴影覆盖。实际截图见 `docs/screenshots/river-boat-heading/02-wide-map.png`。
