# 温柔饱满的水域配色

参考用户提供的《Derby Creek》视频：https://www.bilibili.com/video/BV1uzYM6sENk/ 。实际查看溪水、草地和树木画面后，采用暖黄绿草地、灰蓝水域、奶油色沙岸、蜂蜜金和蓝灰界面的组合。提高暗部亮度并保留色相层次，避免荧光色、纯黑阴影和刺眼纯白。

配色集中在 scripts/visual_theme.gd。地面着色器分别映射深水、浅水、草地、沙岸和湖床，沿用原始地形分类和水位遮罩；湖水四季使用同一配色。夏季草地更鲜活，秋季呈柔和杏金色，冬季为略带暖色的雪白。外围树冠也跟随四季，景物着色器轻微抬升建筑、鸟类和植物暗部，保留原图的像素细节。

菜单按钮、面板、文字、阴影和遮罩使用同一组蓝灰、奶油白、淡金和嫩绿色。红色危险操作和指标颜色仍可辨认。卡牌内容、布局及玩法保持现有实现。

地图外地面和中央地面使用同一个原始草色作为亮度基准，季节效果连续覆盖摄像机视野。彩蛋面部保持独立材质及高于地面的绘制位置；花丛和飘雪继续避让彩蛋。

实际渲染检查输出保存在 docs/screenshots/soft-palette：season-0.png至season-3.png是对局四季画面，menu-season-0.png至menu-season-3.png是主菜单四季画面。seasonal_scenery覆盖季节、窗口比例、外围颜色、边界连续、彩蛋可见性、湖水跨季节一致性及随机数和生态状态不变。

最终检查：seasonal_scenery通过12078项、map_render通过801项，均零断言失败；17625个水面像素未受到接触阴影影响。退出诊断的两项引用残留来自原有BGM的AudioStreamMP3及AudioStreamPlaybackMP3，并非新配色材质。
