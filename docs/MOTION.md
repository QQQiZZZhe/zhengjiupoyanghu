# 游戏动效与独立 GSAP 预览

本次按照用户选择保留 Godot/GDScript 运行时。游戏执行原生 Tween；真实 GSAP 3.15.0 仅在独立开发预览中执行，没有为游戏引入 JavaScript 运行环境。

后续 motion-web 适配还加入了原生弹簧、惯性滚轮、独立物理芦苇和湖面水鸟交互，具体位置、来源许可与验证见 [MOTION_WEB.md](MOTION_WEB.md)。

## onetake 的适配

技能来源：[feitangyuan/onetake](https://github.com/feitangyuan/onetake)。已安装到本机 Codex skills。这里应用它的动效词汇、因果衔接、静止段落、明确主体及确定性预览方法；短片配音、4K 离线渲染、视频剪辑节拍验收不适用于玩家实时交互，因此不强制加入游戏。

| 场景 | 如何承接动作 | 实现 |
|---|---|---|
| 手牌选择与按钮 | 输入先得到快速反馈，再落定 | response / 可中断按钮反馈 |
| 行动卡、知识卡详情 | 原卡让出卡面，详情代理从原位置展开，返回同一来源 | carry / return；中断、关查看器、销毁代理均恢复来源 |
| 牌库、知识图鉴、调度入场 | 按顺序错开，进入后静止等待操作 | enter，expo.out；保留现有像素美术 |
| 手牌排序 | 卡片先收拢，再按新顺序发出 | gather / deal，共享时长、错开间隔 |
| 出牌与结算 | 出牌主体传递到指标与沙盘，终点仍使用真实结算值 | 原有分段演出纳入公共曲线；指标条、小票连续重定向 |
| 主菜单镜头、手牌收放 | 同一个沙盘与摄像机，从当前位置接续 | camera / focus；保持已有暂停和减弱动效支持 |
| 成就、提示、危机、弹窗、季节指针 | 有目的的到达、停留、离开；不新增无意义漂浮 | 原生序列统一入口；重复警示、文字与季节指针可取消旧动画 |
| 水面、鸟类、船只、植物、雪雨、陀螺仪 | 环境实时模拟与输入响应 | 保留原生逐帧模拟、着色器及既有暂停；不转换为离线影片时间轴 |

`scripts/motion.gd` 统一 Tween 创建和缓动名称；`assets/motion/profiles.json` 共享主要交互节奏。GSAP 的 `power2` 对应三次曲线、`power3` 对应四次曲线；Godot 使用对应的原生曲线。`back` 的具体超调参数由各引擎默认值决定，不宣称两个渲染器逐像素相同。Windows 导出配置已包含新 JSON。

带 channel 的动画在同一节点上替换旧序列，不回到旧起点；不同 channel 可并行。Tween 继续绑定节点生命周期，由现有暂停代码控制，不创建另一套逐帧运行器。公共入口也覆盖旧版保留的 3D 演出代码，但这些代码不因此重新启用。

## 独立预览

在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/tools/motion_preview/>。支持播放、暂停、重播、0.5–2 倍速以及任意时间拖动。8.2 秒示例由同一张卡贯穿：选择 → 详情 → 阅读停留 → 返回 → 收拢发牌 → 出牌 → 指标结算 → 归位静止。

`window.__seek(t)` 和 `window.__track()` 用于确定性检验；预览使用真正的 `gsap.timeline()`，并使用 onetake 动效库的 `press` / `ripple` 表现接触原因。它展示主要交互节奏，属于独立预览，不替代 Godot 实际渲染测试，也不是录像。

GSAP 及 onetake 原始版权头与许可证保留在 `tools/motion_preview/vendor`。onetake 动效库采用 PolyForm Noncommercial 1.0.0：此库位于开发预览中，禁止商业使用；商业预览需另获授权或移除该库。整个 `tools` 目录在游戏导出中排除，原生运行时不依赖 onetake 的 JavaScript 文件。

## 验证

`tests/motion_lifecycle.tscn` 验证重定向不跳帧、channel 隔离、旧回调取消、暂停/恢复、源卡恢复及节点销毁。`card_gyro` 添加详情连续性、减弱动效和窗口变化断言。其余引擎场景验证卡面、地图、四季、算分、沙盘、成就与界面行为。

2026-10-08：Godot 4.7.2 Mono 隔离存档实渲染回归 18/18 场景通过，全部场景退出码为 0、脚本错误为 0。最终详情衔接修正后再次验证生命周期、卡牌陀螺仪与详情、视觉总回归及知识卡场景，其中生命周期 18 项、卡牌陀螺仪与详情 464 项、视觉总回归 941 项通过。独立预览用 Edge/Playwright 验证 22 项：8 个时刻来回定位后几何及像素相同、主体始终入框、阅读段真正静止、暂停冻结和变速正确。

Windows Desktop 资源包导出后，在空项目中加载验证 5/5 项通过：资源包可加载、共享 JSON 存在、编译后的 Motion 脚本可调用，GSAP 和 onetake 的预览库均不在包内。此项验证资源包，不代表已完成 Windows 可执行文件发布。
