# 运行开销优化（2026-10-09）

这次优化保留动画时长、弹簧参数、逐帧轨迹、画面精度、命中轮廓、遮挡规则与全部游戏数值。没有降低帧率、减少动效、删除场景物件或缩减贴图。

## 修改

- 湖景固定几何由生成/重置函数维护版本，不再每帧深度哈希整个草木和房屋列表。固定场景列表通过原生数组复制，再用同一个深度比较器二分插入鸟和船，避免每帧在 GDScript 中遍历合并数百项。
- 弹簧到达静止状态后，同一目标不再重新启动处理。记录实际存储的静止值，外部动画改变位置或新目标出现时仍会唤醒；延迟、速度和交接保持原逻辑。属性 NodePath 只创建一次。
- 卡牌选中框保留本地轮廓坐标与绘制命令。移动/缩放/旋转由 CanvasItem 处理，颜色呼吸仍照常更新；只有脸面布局发生变化才重建轮廓，不变的框不再每帧重绘。
- 指标悬停推演缓存按指标、难度、回合、种子、本回合行动和待爆发危机失效。缓存只存在内存中，不写存档；返回深拷贝，避免调用者修改结果污染下次查询。

## 实测

同一台 RTX 4060 Laptop / Godot 4.7.2 设备，同一隔离测试场景，使用 Time.get_ticks_usec 测量。微基准不等于整个游戏帧率提升，运行间有正常波动。

| 工作负载 | 优化前 | 优化后 | 降幅 |
| --- | ---: | ---: | ---: |
| 湖景更新 1200 次 | 333626 μs | 73619 μs | 约 78% |
| 静止弹簧重复请求 10000 次 | 42476 μs | 10940 μs | 约 74% |
| 同一指标提示 1000 次 | 242227 μs（原计算） | 3619 μs（缓存） | 约 98.5% |
| 不变的选中框，30 帧 | 重绘 30 次 | 重绘 0 次 | 消除重复绘制 |
| 静止弹簧，10000 次请求 | 唤醒 10000 次 | 唤醒 0 次 | 消除重复处理 |

## 验证

`tests/runtime_performance.tscn` 的 796 项检查涵盖完整渲染列表与直接全排序参考逐项一致、季节过渡、种子重置、植物增长、卡牌轮廓在移动/旋转/缩放时与原坐标计算一致、重选/取消/改色/改尺寸、弹簧外部位置更新和中途改目标、四种难度/季节/边界指标/危机/行动/种子下的推演结果，以及返回值隔离和全局 RNG 不变。

旧陀螺仪测试用固定 450 ms 判定弹簧已完成回位，在优化前后均有两项相同失败；改为最多等待 1 秒内实际收敛，再保持原有位置误差断言。游戏中的弹簧和动效参数没有改变。

运行测试需使用独立存档目录。可用 `python tests/prepare_visual_test.py runtime_performance` 创建项目副本，再以 Godot 打开该项目。真实输入和截图测试应在图形窗口运行；headless 不处理这些真实鼠标命中。

最终真实窗口回归结果：runtime_performance 796 项、card_gyro 690 项（刚性投影 1665 个内部采样零误差）、motion_web 48 项、rapid_settlement 160 项、metric_effects 67 项、motion_lifecycle 18 项全部通过；animation_performance 与 zoom_performance 均为零失败。

导出：`build/鄱阳归翎-生态修复手记_性能优化版.exe`。
