# 湖外四季景色 0.1.14

春季保留现有景色，夏季外围草地更绿并增加粉、黄、紫、白色花丛；秋季外围草地和树冠金黄；冬季覆盖更白的像素积雪，外围树冠沿顶端轮廓覆盖连续积雪并飘落雪花。

256×256 陆地遮罩从地图边缘连通填充，排除孤立湖内小岛。地面着色仅处理原有外围绿色陆地，排除河岸、湖床和当前被淹没区域。新增花丛和雪花额外避让河道、湖边、社区房屋和隐藏景物。湖内生态植物不使用外围树冠变体。

移除原先整张地图的季节色调，确保水域不被换季染色。水位涨落、水质、植被、候鸟及社区仍由生态状态驱动。装饰使用独立固定种子，不消耗游戏随机数，不改变数值。减少动态效果时停用飘雪，保留静态积雪；每帧最多绘制180片雪花。

验证：独立用户目录中的 seasonal_scenery 测试通过3544项检查；覆盖四季同步、花丛位置、随机数及生态数值不变、湖水像素跨季节一致、秋冬地面变化。四季截图保存在 docs/screenshots/seasonal-scenery。测试截图只切换绘景状态，因此HUD仍显示测试回合的春季；正常游戏使用实际回合季节同步。

全视野修复：地面根据摄像机四角在地面上的投影扩展，覆盖菜单拉远、手牌视角和窗口比例变化。原地图保持原始尺寸及UV；地图外使用外围草地的同一季节着色函数，避免绿色背景边框和河湖边缘贴图被拉伸。外围花丛和飘雪采样将地图外视为草地，仍避让实际河道。彩蛋空地也使用季节地面材质，彩蛋面部贴图继续保持高于地面0.03的绘制位置，保留原有概率和装饰避让范围。
