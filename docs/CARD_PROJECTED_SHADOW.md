# 固定光源卡牌投影（0.1.8）

此前 `VisualTheme.card_style()` 的 StyleBox 阴影随卡面材质的顶点旋转，表现为贴在卡牌上的阴影。现在卡牌样式阴影为零，绑定陀螺仪时生成独立的 `ProjectedCardShadow` 绘制节点，不继承卡面材质、不接收输入，在卡面后方绘制。

使用屏幕左上方的固定方向光，光线朝右下方和背景传播。卡牌四个角使用与 `card_rigid_projection.gdshaderinc` 相同的旋转顺序，再沿光线投到固定背景深度，最后使用同样的 520 像素相机距离进行透视投影。背景深度由显示尺寸确定，保持在允许倾斜范围的卡面后方；接收平面不跟随卡面倾斜。半影用多层透明轮廓近似，随卡片与背景间距调整宽度。

投影节点随卡牌销毁，复用绑定不会重复生成。手牌的平面扇形旋转与缩放也纳入坐标转换，固定光源不会跟着手牌旋转。选择与悬停仍保留原有边框，闪箔仍使用原来的卡面透视。

隔离存档下图形回归通过：333 项检查、0 失败。覆盖独立材质、前后层次、相反陀螺仪方向产生不同四角投影、回正，以及手牌、行动图鉴、紧急调度、已收集/未收集知识卡和最小窗口检视。刚性卡面投影比对 1665 个内部采样点，0 误差。截图保存在 `docs/screenshots/projected-card-shadow/`。

后续收近阴影：将屏幕光线方向从(0.40, 0.65)调整为(0.14, 0.22)，相当于把灯移向卡牌正上方，使横向及向下拖影约缩短三分之二。半影系数从0.055收窄到0.035，上限由13像素收至8像素。背景接收深度及卡面旋转、透视关系保持原有实现，因此倾斜时仍有独立投影，手牌下方不再堆积大片拖影。新截图保存在docs/screenshots/closer-card-shadow。
