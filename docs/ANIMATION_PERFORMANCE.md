# 动画流畅度与 CPU 优化

保留船速、鸟类行为、四季切换时长、卡牌悬停/点击反馈、闪箔和彩蛋；景物从原来的 24 Hz 重绘限制改为逐帧刷新。旧计时器直接清零，在稳定 60 FPS 下通常实际只有 20 Hz。

固定景物按水位、植物状态、季节进度、地图布局和相机投影缓存排序，每帧仅排序移动鸟类并合并两份有序列表。阴影仅在相关状态或投影变化时重新生成。地形以原始 RF 浮点数组做同样的双线性采样，并用最多 8192 项的缓存复用固定位置。河道使用累计距离和二分查找，保持原来的距离参数化与航向。静止卡牌跳过相同材质参数与阴影更新，悬停、点击、尺寸、纹理及全局变换变化仍触发更新；闪箔 shader 的时间动画继续运行。

测试环境：Godot 4.7.2、Compatibility、RTX 4060 Laptop、同一隔离测试项目与默认场景。基线使用修改前的景物排序、阴影刷新、河道线性采样和地形 Image 读取逻辑；基线文件仅保存在忽略的 build 目录。以下为同步 CPU 计算耗时，不含 GPU 绘制，不表示整个游戏的 FPS 提升。

| 测量 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 景物刷新 600 次 | 3,985,025 μs | 195,064 μs |
| 单次景物刷新平均 | 6.64 ms | 0.33 ms |
| 河上船位置/航向采样 3000 次 | 39,089 μs | 14,837 μs |
| 地形采样 100000 次 | 45,285 μs | 42,602 μs |

地形缓存限制了内存占用，测试刻意使用 10000 个不同位置，因此缓存收益有限；固定景物采样可重复利用缓存。地形 checksum 前后完全一致（17034.256068599）。

验证：animation_performance 检查河道位置/方向与旧算法一致、地形双线性采样一致、每帧移动鸟类快照及深度排序；map_render 2420 项检查通过，包括水色和阴影遮罩；seasonal_animation 4042 项检查通过；card_gyro 435 项检查通过。暂停和减少动态设置继续沿用原行为。
