# 素材轮廓与卡牌命中（0.1.9）

卡牌布局为 122×165，但素材比例为 96×144，按比例居中后两侧留白。此前黄框和命中范围采用整个容器，造成错位。

现在 `card_geometry.gd` 统一计算 TextureRect 实际绘制矩形。`card_outline.gd` 从素材 alpha 提取轮廓，沿轮廓绘制黄框，使用与卡面相同的陀螺仪材质；容器不再绘制矩形边框。选中呼吸颜色仍由原 StyleBox 驱动。

命中时先将鼠标屏幕点的相机射线与倾斜卡面相交，再逆转卡面旋转和显示缩放，映射到素材像素，仅 alpha 大于 0.5 的区域有效。手牌、图鉴网格、紧急调度和详情统一使用这一逻辑；不使用会包含抬起前位置的旧矩形。知识卡闪箔的矩形和透明遮罩同步匹配素材。

隔离测试覆盖各类卡牌的倾斜命中，素材中心与两侧内部可点击，外侧留白和透明圆角不可点击；保留刚性透视与独立阴影回归。截图在 `docs/screenshots/card-art-outline/`。
