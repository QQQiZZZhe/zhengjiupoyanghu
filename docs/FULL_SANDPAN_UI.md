# 沙盘模式收起全部常驻界面（0.1.10）

查看沙盘时，手牌向下、常驻 HUD 向右滑出屏幕并隐藏，只保留左下「展开手牌」按钮。HUD 包括左右面板、事件文字、投入档位、行动图鉴入口、危机历史入口、排序/紧急调度/刷新/执行按钮以及界面渐暗底层。弹窗、暂停菜单与独立详情层保持原有行为。

包装层的平移不改子控件的锚点、位置或可见状态，恢复精确归零，避免把原本隐藏的面板错误展开。切换过程中暂停冻结两层动画，连续切换会取消旧动画；窗口变化重新计算离屏距离。减少动态效果直接切换。非出牌阶段、结算和退出恢复包装层。

排序按钮在收起期间持续禁用，`_toggle_hand_sort()` 入口也检查收起状态，防止隐藏按钮或回调触发排序。隐藏期间不处理手牌悬停。保留原卡牌、选中档位、预算与存档。

隔离存档图形回归：`SANDPAN_VIEW: PASS (67 checks, 0 failures)`，覆盖只保留切换按钮、排序回调不改变状态、准确恢复、暂停、快速切换、窗口变化、减少动态效果和完整结算。截图见 `docs/screenshots/full-sandpan-ui/`。
